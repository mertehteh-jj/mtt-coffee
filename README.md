# ระบบต้นทุนและสต๊อกกาแฟ "เม่อะ เต เต"

แอปบันทึกต้นทุนกาแฟตั้งแต่กาแฟกะลาจนถึงซองพร้อมขาย เก็บข้อมูลทั้งหมดใน Google Sheets

```
1 ซื้อกะลา ──► 2 ผลิตสารเขียว ──► 3 ผลิตเมล็ดคั่ว ──► 5 ขาย
                    │                 (4 ระดับคั่ว)
               ขายเป็น kg ได้      4 ซื้อวัสดุอุปกรณ์
                                          │
                        6 สรุป: ต่อซอง · ต่อวัน · ต่อเดือน · ต่อปี
```

## ไฟล์ในโปรเจกต์นี้

| ที่อยู่ | คืออะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (หน้าจอ + ตรรกะฝั่งผู้ใช้) |
| `manifest.json` · `sw.js` · `icon-*.png` | ไฟล์ที่ทำให้ติดตั้งลงหน้าจอโฮมมือถือได้ และใช้ออฟไลน์ได้ |
| `_headers` | กำหนดว่าไฟล์ไหนแคชได้นานแค่ไหน **อย่าลบ** ไม่งั้นอัปเดตแล้วเครื่องผู้ใช้ไม่เห็นเวอร์ชันใหม่ |
| `apps-script/Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ ต้องคัดลอกไปวางใน Apps Script ของสเปรดชีตเอง |
| `docs/คู่มือติดตั้ง.md` | คู่มือฉบับเต็ม วิธีใช้งานทุกหน้าจอ และวิธีแก้ปัญหา |
| `docs/ทำเป็นแอปแอนดรอยด์.md` | วิธีทำเป็นไฟล์ APK และขึ้น Play Store |
| `.well-known/assetlinks.json` | ไฟล์ยืนยันความเป็นเจ้าของโดเมน ใช้ตอนทำแอป Android |

ไฟล์เว็บอยู่ที่โฟลเดอร์บนสุด จึงใช้ได้ทั้ง Cloudflare Pages และ GitHub Pages โดยไม่ต้องตั้งค่าเพิ่ม

> **ไม่มีข้อมูลลับในโค้ดนี้** URL ของ Apps Script ผู้ใช้เป็นคนกรอกเองในแอปและเก็บไว้ในเครื่องตัวเอง ไม่ได้ฝังอยู่ในไฟล์ จะตั้ง repo เป็น public หรือ private ก็ปลอดภัยทั้งคู่

## ครั้งแรก: เอาโค้ดขึ้น GitHub

**วิธีที่ง่ายที่สุด ไม่ต้องลงโปรแกรมอะไรเลย**

1. สมัคร/เข้าสู่ระบบที่ https://github.com
2. กดปุ่ม **+** มุมขวาบน → **New repository**
3. ตั้งชื่อ เช่น `mtt-coffee` · เลือก **Private** ถ้าไม่อยากให้คนอื่นเห็น · กด **Create repository**
4. ในหน้าที่ขึ้นมา กดลิงก์ **uploading an existing file**
5. ลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้เข้าไปวาง
6. ใส่ข้อความสั้น ๆ ในช่อง commit เช่น `เวอร์ชันแรก` แล้วกด **Commit changes**

## เชื่อม GitHub เข้ากับ Cloudflare Pages

ทำครั้งเดียว หลังจากนี้แก้โค้ดบน GitHub แล้วเว็บอัปเดตเองอัตโนมัติ

1. เข้า https://dash.cloudflare.com → **Compute (Workers & Pages)** → **Create** → แท็บ **Pages**
2. เลือก **Connect to Git** แล้วอนุญาตให้ Cloudflare เข้าถึง repo ที่เพิ่งสร้าง
3. ตั้งค่าตอน build ให้ **เว้นว่างทั้งหมด**

   | ช่อง | ใส่อะไร |
   |---|---|
   | Framework preset | None |
   | Build command | *(เว้นว่าง)* |
   | Build output directory | `/` |

4. กด **Save and Deploy**

ได้ลิงก์ `https://ชื่อโปรเจกต์.pages.dev` เอาไปติดตั้งลงหน้าจอโฮมมือถือได้เลย

### ถ้าอยากใช้ GitHub Pages แทน

repo → **Settings** → **Pages** → Source เลือก **Deploy from a branch** → เลือก branch `main` และโฟลเดอร์ `/ (root)` → **Save**

ได้ลิงก์ `https://ชื่อผู้ใช้.github.io/mtt-coffee/`

ข้อแตกต่าง — GitHub Pages ใช้ได้ฟรีเฉพาะ repo แบบ public (ถ้า private ต้องเสียเงิน) และไม่รองรับไฟล์ `_headers` ส่วน Cloudflare Pages ใช้กับ repo private ได้ฟรีและอ่าน `_headers` ให้

## เวลาแก้ไขแอปภายหลัง

1. เข้า repo บน GitHub → กดที่ไฟล์ที่จะแก้ เช่น `index.html`
2. กดรูปดินสอ ✏️ มุมขวาบน แก้ในหน้าเว็บได้เลย
3. กด **Commit changes** ใส่ข้อความสั้น ๆ ว่าแก้อะไร

Cloudflare Pages จะสร้างเวอร์ชันใหม่ให้เองภายใน 1-2 นาที ลิงก์เดิมชี้ไปเวอร์ชันใหม่อัตโนมัติ

**ข้อดีที่ได้จากการเก็บโค้ดบน GitHub** — ทุกครั้งที่แก้จะมีประวัติเก็บไว้ว่าแก้อะไร เมื่อไหร่ ถ้าแก้แล้วพัง กดย้อนกลับไปเวอร์ชันก่อนหน้าได้ (ที่แท็บ **Commits** → เลือกเวอร์ชันที่ต้องการ → **Revert**) ต่างจากการลากไฟล์อัปโหลดตรง ๆ ที่ถ้าเขียนทับแล้วของเดิมหายเลย

**สำคัญ** — ถ้าแก้ `apps-script/Code.gs` บน GitHub ต้องคัดลอกไปวางใน Apps Script ของสเปรดชีตเองด้วย เพราะ GitHub กับ Google ไม่ได้เชื่อมกันอัตโนมัติ ไฟล์ในนี้เก็บไว้เป็นต้นฉบับและประวัติการแก้เท่านั้น

## ติดตั้งฝั่ง Google Sheets

ดูขั้นตอนเต็มใน [`docs/คู่มือติดตั้ง.md`](docs/คู่มือติดตั้ง.md) โดยย่อคือ

1. สร้าง Google Spreadsheet ใหม่ → **ส่วนขยาย → Apps Script**
2. วางเนื้อหาจาก `apps-script/Code.gs` แล้วบันทึก
3. รันฟังก์ชัน `setupSheets` แล้วตามด้วย `seedCoffeeCatalog`
4. **ทำให้ใช้งานได้ → เว็บแอป** → ดำเนินการในฐานะ *ฉัน* → เข้าถึงได้ *ทุกคน*
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปวางในหน้าตั้งค่าของแอป

## ฟังก์ชันดูแลระบบใน Apps Script

| ฟังก์ชัน | ใช้เมื่อไหร่ |
|---|---|
| `setupSheets` | ครั้งแรก และทุกครั้งที่อัปเดตโค้ด |
| `seedCoffeeCatalog` | ครั้งแรก สร้างรายการสินค้าตั้งต้น |
| `seedBoxSizes` | เพิ่มขนาดกล่องพัสดุมาตรฐาน |
| `archiveEmptyLots` | เดือนละครั้ง ย้ายล็อตที่ใช้หมดแล้วไปเก็บ ช่วยให้ระบบไม่ช้าลง |
| `deleteAllSales` | ล้างรายการขายทั้งหมดพร้อมคืนสต๊อก |
| `dailyAlert` | ตั้งเป็นทริกเกอร์รายวัน ส่งอีเมลเตือนของใกล้หมดอายุและของใกล้หมด |
